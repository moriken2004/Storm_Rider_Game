# セットアップ

## 方法 1：ファイルを開くだけ（おすすめ）

1. リポジトリのページで **Code → Download ZIP** を押して展開します。
2. `index.html` をダブルクリックします。

これだけです。`index.html` は 1 枚で完結していて、ほかのファイルを必要としません。

## 方法 2：ローカルサーバーで動かす

ソースを書き換えて試すときや、自分の音源を鳴らしたいときはこちらを使います。[Node.js](https://nodejs.org/) 18 以上が必要です。

```bash
git clone https://github.com/moriken2004/Storm_Rider_Game.git
cd Storm_Rider_Game
node serve.mjs
```

ブラウザで <http://127.0.0.1:8795/> を開きます。止めるときは `Ctrl + C` です。

Node.js がなくても、Python があれば同じことができます。

```bash
python3 -m http.server 8795 --bind 127.0.0.1
```

macOS では `start.command` をダブルクリックすると、サーバーの起動とブラウザを開くところまで自動で行います。

## 方法 3：GitHub Pages で公開する

自分のリポジトリに複製（フォーク）して、**Settings → Pages → Branch を `main`、フォルダを `/ (root)`** にすると、
`https://<ユーザー名>.github.io/Storm_Rider_Game/` で誰でも遊べるようになります。

## 動作環境

- WebGL 2 に対応したブラウザ（Chrome／Edge／Safari／Firefox の最近の版）
- 内蔵グラフィックスのノート PC でも動きます。重いときは「設定 → 画質」を「軽量」にしてください。
- 初回の読み込み時だけインターネット接続が必要です（three.js と書体を配信サービスから読み込みます）。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 真っ黒のまま進まない | ブラウザを最新版にする。別のブラウザで試す。ハードウェアアクセラレーションが無効になっていないか確かめる。 |
| 「起動に失敗しました」と出る | インターネットに接続して再読み込みする（three.js を読み込めていません）。 |
| 動きが重い | 「設定 → 画質 → 軽量」。ブラウザのウィンドウを小さくする。ほかのタブで動画やゲームを閉じる。 |
| 音が出ない | 画面をどこか 1 回クリックする（ブラウザは操作があるまで音を出しません）。それでも出なければ「設定 → 音が出ないとき → 音声を再起動」。 |
| 文字の書体が違って見える | Google Fonts を読み込めていません。遊ぶのに支障はありません。 |
| 放置したら「休止中」と出た | 5 分間操作がないと描画を止めます。クリックかキー操作で戻ります。 |

設定（音量、上下反転、画質、難易度、機体の形と塗装）はブラウザに保存されます。消したいときは、ブラウザのサイトデータを消してください。

## 好きな音楽を BGM にする

音楽は標準では内蔵のシンセサイザーが演奏しますが、手元の音楽ファイルに差し替えられます。

```bash
node bgm/setup.mjs ~/Music/my_song.mp3
node serve.mjs
```

曲を自動で解析して、タイトル・嵐・台風の目・再攻撃・締めくくりに合う部分を選び、つなぎ目の目立たない繰り返し区間まで決めます。
[ffmpeg](https://ffmpeg.org/) が必要です。ファイルは PC の中だけで処理され、リポジトリにも入りません。

くわしい使い方、つなぎ目の確かめ方、手での調整は [bgm/README.md](../bgm/README.md) を見てください。

元に戻すには `node bgm/setup.mjs --remove` です。

# 好きな音楽を BGM にする

このリポジトリに音楽ファイルは入っていません。ゲームは標準で、内蔵のシンセサイザーが音楽を演奏します。

手元に音楽ファイルがあれば、次の 1 行でゲームの BGM にできます。ファイルはあなたの PC の中で処理され、どこにも送信されません。

```bash
node bgm/setup.mjs <音楽ファイル>
```

例：

```bash
node bgm/setup.mjs ~/Music/my_song.mp3
node serve.mjs          # → http://127.0.0.1:8795/ を開く
```

設定画面の「音楽の音源」が「手元の音源」になっていれば成功です。

必要なものは、Node.js 18 以上と [ffmpeg](https://ffmpeg.org/) です（macOS：`brew install ffmpeg`、Windows：`winget install ffmpeg`）。
mp3・wav・m4a・flac など、ffmpeg が読める形式なら使えます。曲の長さは 1 分以上、できれば 3 分以上が向いています。

## 何をしているか

1. 音楽ファイルを `bgm/src/storm_rider.mp3` に変換して置きます。
2. 曲全体の音量と音色の移り変わりを調べ、場面に合う部分を選びます。

   | 場面 | 選びかた |
   |---|---|
   | タイトル・出撃・帰還（theme） | 曲の前半で、音量が上がって落ち着いた最初の部分 |
   | レインバンド・壁雲（storm） | 中盤でいちばん激しい部分 |
   | 台風の目（eye） | いちばん静かな部分 |
   | 再攻撃（climax） | 終盤でいちばん激しい部分 |
   | コア消滅（victory） | 曲の締めくくり（1 回だけ鳴らす） |

3. それぞれの部分で、「頭に戻っても不自然にならない」繰り返しの開始点と終了点を探します。
   2 秒ぶんの音色の並びがいちばんよく似た 2 点を選び、拍がはっきりした曲では、長さが拍の整数倍になる組を優先します。
4. 結果を `bgm/cues.json` に書きます。ゲームは起動時にこれを読みます。

実行すると、選ばれた区間と評価が表示されます。

```
  theme     タイトル・出撃・帰還     0:37 – 1:02     一致度 0.86　音量差 -0.8dB　56.04 拍
  climax    再攻撃                  2:59 – 3:18     一致度 0.94　音量差 +0.5dB　44.06 拍
```

- **一致度** — 1 に近いほど、つなぎ目が自然です。0.8 未満には △ が付きます。
- **音量差** — 繰り返しの終わりと始まりの音量の差です。3dB を超えると △ が付きます。
- **拍** — 繰り返しの長さが何拍ぶんか。整数に近いほど、リズムが途切れません。

## つなぎ目を聴いて確かめる

```bash
node bgm/setup.mjs <音楽ファイル> --preview
```

`bgm/work/seam_theme.wav` などが書き出されます。繰り返しの終わり 4 秒と始まり 4 秒をつないだもので、4 秒目がつなぎ目です。

気になるときは、`bgm/cues.json` の秒数を手で直してください。

```json
"storm": { "start": 131.2, "loop": [148.24, 162.75] }
```

- `start` — その場面に入ったとき、どこから鳴らし始めるか
- `loop` — 繰り返す区間（開始秒、終了秒）
- `once` — 1 回だけ鳴らす区間。`next` に、鳴り終わったあとへ続く場面を書きます
- `vol` — その場面だけ音量を変えたいとき（1 が標準）

## 元に戻す

```bash
node bgm/setup.mjs --remove
```

取り込んだ音源と設定を消して、内蔵シンセに戻します。URL の末尾に `?synth` を付けると、音源を残したまま一時的に内蔵シンセで遊べます。

## 知っておくこと

- `index.html` をダブルクリックして開いた場合は、ブラウザの制限で音源を読み込めません。`node serve.mjs` で起動してください。
- `bgm/src/`、`bgm/work/`、`bgm/cues.json` は `.gitignore` で除外してあり、リポジトリには入りません。
- **他人が権利を持つ楽曲を、公開のリポジトリや Web サイトに置かないでください。** この仕組みは、自分の PC で自分だけが聴くためのものです。
- `analyze.py` と `loops.py` は、同じ解析を Python（numpy）で行う古い版です。曲の構造を細かく調べたいときの参考に残してあります。
